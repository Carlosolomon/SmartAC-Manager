# SmartAC-Manager
SmartAC Manager is an IoT-based system for automating and controlling air conditioners in mosques (or other buildings) via an Android app. Supervisors can schedule AC operations (ON/OFF, temp, fan) aligned with prayer times or occupancy Times, reducing energy waste and manual effort.
ESPs should be configured with an IR Communication module and installed near the AC unit, each esp32 is responsible for its corresponding AC unit. The ESP Arduino code will be shared separately later. 

**Work in Progress** – Documentation and setup guide coming soon!  

- Android app: Java (Android Studio)  
- Hardware: ESP32 configured with IR Communication module. 
- Features: Scheduled AC control, control ACs
